# 动效与兼容

视觉风格与动效独立选择。先完成 style-selection.md 的内容与场景判断，再决定是否需要运动。下述圆环案例是用户给定参考的专项方案，不是本 Skill 的默认模板。普通经营复盘、数据研究或教学页不因调用本 Skill 而自动出现圆环。

## 参考录屏的实际观察

用户补充的 `Video Project.mp4` 约 5.03 秒、1920×1080，画面中包含被录制的播放器与黑色边缘。已按约 0.2 秒间隔查看画面。只能确认视觉表现，无法据此确认原文件使用的转场工具、缓动曲线、真实播放速度和对象结构。

| 录屏时间，约 | 可见表现 | 可借鉴的原则 |
| --- | --- | --- |
| 0.4–0.8 秒 | 风景图沿圆弧分区切换，标题保持水平并向上移动 | 图片的方向变化与文字交接分开处理 |
| 1.2–1.8 秒 | 蓝紫色湖景切到金色山景，环形分区延续，旧文字上移、新文字由下方进入 | 共享圆心与视觉轮廓，把前后画面接成连续空间 |
| 2.2–2.8 秒 | 山景切到峡谷，分区边缘旋转并伴随层次遮挡 | 保留对象身份与叠放次序，避免突然跳到另一张布局 |
| 3.4–4.0 秒 | 峡谷转向森林，文字再次交接 | 用稳定的文字区域承接变化的图片 |
| 4.4–5.0 秒 | 圆环收拢到页面中部，作为内容入口 | 让动效的终态承担章节导航或主题强调作用 |

录屏中每个终态停留很短，属于效果展示；正式汇报需要留足阅读时间，并由演讲者点击推进。不要照抄录屏速度、照片、英文文案、字幕、边框和水印。

## 可选择的转场方案

优先依据内容选择，不能只给所有页写入 Morph 就声称复现了参考效果。

| 方案 | 适用场景 | 设计与建议时长 |
| --- | --- | --- |
| 同一主图连续移动 | 同一对象的全景、细节或阶段解释 | 固定一个视觉锚点，改变位置或轻微缩放，Morph 约 0.55–0.85 秒 |
| 圆环分区旋转 | 章节切换、同一主题的多个视角 | 分区共用圆心、半径和叠放关系，保持方向一致，约 0.8–1.2 秒 |
| 文字水平交接 | 前后页内容更换且主视觉连续 | 旧文字淡出、新文字淡入，可加约 16–32px 的竖向位移，约 0.25–0.45 秒；按字号与画布调整 |
| 局部轻旋转 | 示意图强调、视角收拢 | 主对象从 -6° 到 0° 等小角度变化，约 0.7–1.0 秒，正文保持水平 |
| 短淡化 | 独立论述页、较密集表格或数据页 | 约 0.25–0.4 秒，保留完整稳定的阅读终态 |

这些是本 Skill 的设计建议，不是对视频参数的测量。以 6–10 页普通汇报为例，可以选 1–2 处连续主视觉转场，其余简洁衔接；按叙事需要调整，用户明确要求连贯的全套动效时可增加。不要每页自转、翻屏，或让正文按字飞入。

每次设计应说得清“谁在动、为什么动、从哪到哪”。旋转围绕图片、图解或主题关系展开，不为了动效强行加入巨型关键词，尤其不要挤占普通内容页的解释区域。

## 圆环分区的实现边界

以原生可编辑的图片、裁切或蒙版分区建立主视觉，设计相同圆心的前后状态。各分区保留对应身份，保持分区边界、半径和叠放次序连续；不要用形状本身的局部中心随意旋转，导致环心漂移。需要时采用共用外框或分组固定旋转中心。文字独立于旋转组。

在关键切换前后检查至少起始、中间与终止状态：接缝是否跳变、图片是否露底、裁切是否拉伸、正文是否被环形分区遮挡。如果工具无法可靠导出蒙版、分组或旋转中心，可改用同一主图连续移动或淡化交接，并说明这是简化方案。普通圆形旋转、整页图片淡化和视频贴片均不能冒充已实现的圆环分区旋转。

允许主视觉有层次，但不要把录屏中的全屏风景拼接当作默认商务版式。正文页优先让文字和证据占主要区域，复杂圆环可留给章节或专门的说明页。

## PowerPoint 原生实现

1. 先设计前后状态及需要时的中间状态，再设置转场。相邻两页保留同一对象，复制对象比重新绘制更可靠。
2. 需要强制配对时，两页用相同的 `!!名称`，如 `!!reading-word`，每页只出现一次。
3. 在后一页改变该对象的位置、缩放或旋转。用 Objects 模式。连续的图像分区使用配对名称；替换的正文按不同对象处理，避免把不同段落强制配对后发生文字变形。
4. 将 Morph 加在后一页；首尾普通页面使用淡化或无转场。按点击换页，不添加未经要求的自动跳页。
5. 检查 PPTX 保存后的对象名称、旋转角和转场记录，并在可用时实际播放。

需要对导出的 PPTX 添加原生转场时，可使用 [本地转场脚本](../scripts/set_transitions.py)，仅依赖 Python 标准库：

```bash
python scripts/set_transitions.py draft.pptx animated.pptx --morph-slides 3 --duration 0.85
```

脚本对新文件设置普通页淡化、指定目标页 Morph，并保留旧版播放器的淡化后备分支；不负责建立分区蒙版、旋转中心、对象配对、文字逐项动画或布局。仅有同名对象而前后状态完全相同，也不会产生可见旋转。源文件与输出必须不同，输出不能已存在。脚本检查指定目标页相邻两页有唯一的 `!!` 配对对象。执行后还需检查文件结构与实际播放；它不保证所有播放器的表现一致。对于已有复杂自定义转场的文件，优先使用原创作工具作局部修改。

## 验证分层

- 静态检查：所有终态可读、对象可编辑、角度和旋转中心正确、配对名称唯一；关键解释不能只在运动中短暂出现。
- 文件检查：Morph 写在正确的目标页；无损坏关系、字体丢失和越界。
- 播放检查：PowerPoint 放映或录制，查看卡顿、配对跳变、文本变形、分区接缝和停留节奏。正文需等待下一次点击，不能为追求展示速度自动跳过。

只完成前两层时，明确“已写入并检查配置，尚未实际播放验收”。应用内静态预览和 PDF 没有原生转场。第三方播放器的支持程度不同，不能保证 WPS、Keynote、浏览器均一致。
